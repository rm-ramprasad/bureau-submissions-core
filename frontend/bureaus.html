What each value is for

Member ID
The ID the bureau issued to the NBFC. It goes in the file header and every record, and can be part of the file name.
Member short name
The NBFC's short name in the file header (up to 16 characters).
Header tag
Types that need one (consumer): the header segment tag the bureau expects (for example TUDF for CIBIL).
File name pattern
How the file is named. Fields in braces are filled in: the member ID, the bureau, the cycle, the as-of date and the creation date and time.
Active
Only active bureaus are offered when generating files.
