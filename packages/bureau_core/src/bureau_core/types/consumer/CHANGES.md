# Consumer pack: changes

Every change to this type's rule and format files (`codes.yaml`, `excel_layout.yaml`, `layout.yaml`,
`requirements.yaml`, `rules.yaml`) is a new version here, newest first. The checksum is checked by
`bureau_core/tests/test_pack_versions.py`; each generated file records the version (`out_file.pack_version`).
A change goes live on the day it is deployed.
