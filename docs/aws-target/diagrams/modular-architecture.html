Kill switch, both directions

  • Client exits: revokes bucket policy → we're cut off instantly
  • We exit: disable the client's key → silver & gold unreadable; client deletes them
  • Client keeps bronze, every submission file and audit pack (+ optional one-time gold export by contract)
  • Jobs, mappings, catalog and add-on logic never leave Account 2
  • Contract: curated structure is our IP, deleted on exit

Audit, years later

  • What was submitted? the write-once file
  • From what data? hashed bronze extract
  • What changed, who approved? exceptions log
  • Not altered? manifest hashes vs our ledger
  • Deep dispute: re-run from bronze with the recorded versions → byte-identical file

Portability

  • Runs anywhere: canonical model, mappings, CSV loader, validation, formatters, type packs, add-ons, web app
  • Swap per cloud: FileStore, job dispatch, auth, key service
  • Rewrite per cloud: scheduler, entry handlers, IaC
  • Release: build once → dev → staging → canary client → every client's Account 2, in one pipeline run
  • Locally: API + polling worker, no cloud
